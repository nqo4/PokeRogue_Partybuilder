# 계산 방식이 특이한 기술 모음

기술 데이터에 적힌 분류(물리·특수)와 위력만으로는 실제 데미지 계산을 알 수 없는 기술의 **처리 방식과 대표 예시**를 정리한 문서다.
역할 판정 로직(`prompts/role-logic-redesign.md`)이 이 기술들을 따로 처리하도록 참고 자료로 쓴다.

- **전체 목록**: `reports/special-calc-moves.md` (`node scripts/report-move-lists.mjs`로 생성). 기술마다 게임 설명, 코드 위치, 배우는 포켓몬 전체 표가 있다. 이 문서의 예시가 리포트와 다르면 리포트가 맞다.
- **기준 데이터**: 포켓로그 공식 코드 `vendor/pokerogue/src/data/moves/move.ts`. 각 항목에 해당 클래스 이름을 적었다.
- **기술 이름·위력**: 서비스 데이터 `public/data/dex.json`.
- **배우는 포켓몬**: 최종진화·메가 형태 기준이고, 레벨업과 알기술만 적었다. 기술머신은 범용이라 수만 센다.

| 묶음 | 기준 클래스 | 기술 수 |
|---|---|---|
| 1. 분류 자체가 바뀌는 기술 | `VariableMoveCategoryAttr` | 5 |
| 2. 공격 쪽에 다른 능력치를 쓰는 기술 | `VariableAtkAttr` | 2 |
| 3. 받는 쪽에 다른 능력치를 쓰는 기술 | `VariableDefAttr` | 3 |
| 4. 위력이 상황에 따라 바뀌는 기술 | `VariablePowerAttr` | 76 |
| 5. 능력치와 무관한 고정 데미지 | `FixedDamageAttr` | 14 |
| 6. 기술 타입이 바뀌는 기술 | `VariableMoveTypeAttr` | 15 |
| 7. 2턴에 걸쳐 공격하는 기술 | dex 태그 "2턴에 걸쳐 공격" | 16 |

## 1. 분류 자체가 바뀌는 기술

데이터상 분류는 특수인데, 조건에 따라 **물리기로 바뀌어** 공격 능력치와 상대 방어로 계산된다.

| 기술 | 데이터 | 계산 방식 (클래스) | 판정 로직에서 볼 점 |
|---|---|---|---|
| 포톤가이저 | 특수 100, 에스퍼 | 사용자의 공격이 특공보다 **높으면** 물리 (`PhotonGeyserCategoryAttr`). 같으면 특수. 랭크업·성격까지 반영한 실제 능력치로 비교 | 공격 > 특공인 포켓몬은 **물리 자속기**로 계산 |
| 셸암즈 | 특수 90, 독 | 상대에게 물리·특수로 각각 쳤을 때 예상 데미지를 비교해 **더 센 쪽** 선택 (`ShellSideArmCategoryAttr`) | 어느 분류에도 쓸 수 있는 기술. 분류 판정 증거에서는 **중립**으로 두고, 기술 평가는 주 분류 기준으로 |
| 테라버스트 | 특수 80, 노말 | **테라스탈 중**이고 공격 > 특공이면 물리 (`TeraMoveCategoryAttr`). 테라스탈 타입으로 바뀜 | 테라스탈은 테라오브가 있어야 쓸 수 있고, 거의 모든 포켓몬이 기술머신으로 배움(799종) → 분류 판정에서 **제외** |
| 테라클러스터 | 특수 120, 노말 | 테라버스트와 같은 조건 | 테라파고스 전용에 가까움. 테라스탈 조건부라 할인 |
| 하늘을태우는멸망의빛 | dex 데이터에 없음 | 포톤가이저와 같은 방식 | 서비스 데이터에 없어서 무시 |

**포톤가이저를 배우는 포켓몬 전체** (19종. 네크로즈마만 레벨업, 나머지는 알기술)

| 포켓몬 | 공격 / 특공 | 실제 분류 |
|---|---|---|
| 솔가레오 | 137 / 113 | **물리** 자속 100 |
| 메가뮤츠X | 190 / 154 | **물리** 자속 100 |
| 메가요가램 | 100 / 80 | **물리** 자속 100 |
| 파라블레이즈, 무쇠무인 | 125 / 60, 130 / 120 | **물리** (자속 아님) |
| 뮤·세레비·엠라이트·버드렉스·요가램·가라르 야도란 | 동률 | 특수 (같으면 특수) |
| 뮤츠·메가뮤츠Y·후파·루나아라·네크로즈마·벰크·카디나르마·가라르 야도킹 | 특공이 높음 | 특수 |

> 솔가레오는 공격이 더 높아서 포톤가이저가 **물리 자속기**로 들어간다. 그래서 알기술 포톤가이저는 물리형 증거가 하나 더 늘어나는 것이다 (앞선 정리에서 반례로 넣은 것은 잘못이었다).

**셸암즈를 배우는 포켓몬** (14종)
- 가라르 야도란: 레벨업, 자속
- 나머지 13종은 알기술로 배우고, 모두 자속이 아니다: 킹드라·대포무노·개굴닌자·미끄래곤·대검귀·짜랑고우거 등

## 2. 공격 쪽에 다른 능력치를 쓰는 기술

분류는 물리 그대로지만, 데미지에 **사용자의 공격이 아닌 다른 능력치**가 들어간다. 그래서 사용자 공격이 높다는 근거가 되지 않는다.

| 기술 | 데이터 | 계산 방식 (클래스) | 판정 로직에서 볼 점 |
|---|---|---|---|
| 바디프레스 | 물리 80, 격투 | 공격 대신 **사용자의 방어**로 계산 (`DefAtkAttr`) | 물리형 증거로 쓰지 않음. 대신 **방어 특화 빌드의 공격 수단**으로 평가. 철벽·코튼가드 같은 방어 랭크업과 시너지 (방어를 올리면 화력도 오름) |
| 속임수 | 물리 95, 악 | 사용자 공격 대신 **상대의 공격**으로 계산 (`TargetAtkUserAtkAttr`) | 사용자 공격과 무관하므로 물리형 증거로 쓰지 않음. 공격이 낮은 막이·서포터도 쓸 수 있는 공격 수단 |

- **바디프레스**: 레벨업·알기술로 37종이 배운다.
  - 자속: 브리가론·짜랑고우거(알기술), 자마젠타 역전의 용사(레벨업)
  - 방어가 공격보다 훨씬 높은 예: 보스로라(방어 180 / 공격 110), 메가보스로라(230 / 140), 강철톤(200 / 85), 레지락(200 / 100), 차곡차곡(211 / 131), 크레베이스(184 / 117)
- **속임수**: 레벨업·알기술로 24종이 배운다.
  - 공격이 낮은 예: 블래키(레벨업, 자속, 공격 65), 버랜지나(알기술, 자속, 공격 65)
  - 그 밖에 칼라마네로(레벨업, 자속) 등

## 3. 받는 쪽에 다른 능력치를 쓰는 기술

공격할 때는 특공으로 계산하지만 **상대는 방어로** 받는다 (`DefDefAttr`). 그래서 분류 판정에는 영향이 없다.
- 특수막이(특방이 높은 상대)에게 강하다.
- 이 기술을 쓰는 상대에게는 물리 방어가 중요해진다.

| 기술 | 데이터 | 배우는 포켓몬 (레벨업·알기술) |
|---|---|---|
| 사이코쇼크 | 특수 80, 에스퍼 | 24종. 후딘·슬리퍼·란쿨루스·마폭시 등 (레벨업, 자속) |
| 사이코브레이크 | 특수 100, 에스퍼 | 7종 전부: 뮤츠·메가뮤츠X/Y (레벨업, 자속), 후딘·메가후딘·아그놈·무쇠감투 (알기술, 자속) |
| 신비의칼 | 특수 85, 격투 | 14종. 케르디오 (레벨업, 자속), 초염몽·짜랑고우거·페로코체·무쇠무인 (알기술, 자속), 나무킹·조로아크 등 (알기술) |

판정 로직 반영: 지금 단계에서는 **기록용**이다. 나중에 "특수막이를 뚫는 수단"을 평가에 넣으면 가산점 후보가 된다.

## 4. 위력이 상황에 따라 바뀌는 기술 (76개)

dex 위력을 그대로 쓰면 **과대평가**되거나, 위력이 `-1`(없음)로 적혀 있어 **자동으로 빠지는** 기술이다. 조건 종류별로 묶었다.

| 묶음 | 기술 | dex 위력 기준 | 판정 처리 |
|---|---|---|---|
| 내 HP가 많을수록 강함 (`HpPowerAttr`) | 분화, 해수스파우팅, 드래곤에너지 | 최대치 150 → 과대평가 | 할인. 스피드가 빠르거나 선공이 가능하면 덜 할인. 드래곤에너지는 광역기라 광역기 평가에도 반영 |
| 내 HP가 적을수록 강함 (`LowHpPowerAttr`) | 바둥바둥, 기사회생 | 없음 | 제외 |
| 내 랭크업이 많을수록 강함 (`PositiveStatStagePowerAttr`) | 어시스트파워, 기어오르기 | 최소치 20 → 과소평가 | 랭크업 기술이 있으면 높게 평가 (스위퍼 판정과 연결) |
| 맞은 횟수만큼 강함 (`RageFistPowerAttr`) | 분노의주먹 | 최소치 50 | 막이 성향이면 가산 |
| 연속으로 맞힐수록 강함 | 트리플킥, 트리플악셀 (`MultiHitPowerIncrementAttr`) / 구르기, 아이스볼, 연속자르기, 에코보이스 (연속 사용) | 첫 타 위력 | 트리플킥·트리플악셀은 연속기(보스 대응)로 평가. 연속 사용 기술은 제외 |
| 상대 상태이상이면 2배 (`MovePowerMultiplierAttr`) | 베놈쇼크·독침천발(독), 병상첨병·백귀야행(상태이상), 정신차리기(마비), 잠깨움뺨치기(잠듦) | 기본 위력 | 상태이상 기술이 있으면 시너지 가산. 아니면 기본 위력으로 평가 |
| 상대 HP가 적으면 2배 | 소금물 | 기본 위력 | 기본 위력으로 평가 |
| 내 상태 조건 | 객기(내가 상태이상), 애크러뱃(도구 없음), 분풀이(내 능력이 떨어짐), 열불내기·분함의발구르기(직전 실패) | 기본 위력 | 근성 같은 특성과 함께 있을 때만 가산 (객기 + 근성 등) |
| 행동 순서 조건 | 보복·리벤지·눈사태(나중에 행동하거나 맞은 뒤 2배), 승부굳히기(상대가 이미 맞았으면 2배), 전격부리·아가미물기(먼저 행동하면 2배) | 기본 위력 | 느린 포켓몬의 보복·리벤지·눈사태, 빠른 포켓몬의 전격부리·아가미물기는 2배로 평가 |
| 날씨·필드 조건 | 웨더볼(날씨), 대지의파동(필드), 와이드포스(사이코필드), 라이징볼트·사이코블레이드(일렉트릭필드), 미스트버스트(미스트필드), G의힘(중력) | 기본 위력 | **본인 특성·패시브로 날씨·필드를 만들 때만** 강화된 위력으로 평가 (파티의 다른 포켓몬은 보지 않음) |
| 날씨에 따라 약해짐 (`AntiSunlightPowerDecreaseAttr`) | 솔라빔, 솔라블레이드 | 최대치 | 비·모래바람·눈에서 위력이 줄어듦. 7절 충전기 규칙과 함께 처리 |
| 상대 위치·필드에 따라 바뀜 | 지진·땅고르기·매그니튜드 | 기본 위력 | 기본 위력으로 평가 |
| 효과가 굉장하면 강함 | 액셀브레이크, 라이트닝드라이브 | 기본 위력 | 기본 위력으로 평가 |
| 같은 편과 연계 | 돌림노래, 크로스플레임·크로스썬더, 물의맹세·불꽃의맹세·풀의맹세, 원수갚기, 집단구타 | 기본 위력 또는 없음 | 혼자서는 기본 위력. 연계 효과는 평가하지 않음 |
| 무작위 | 매그니튜드, 프레젠트, 변덕레이저 | 평균과 다름 | 매그니튜드·프레젠트 제외, 변덕레이저는 기본 위력 |
| 무게 (`CompareWeightPowerAttr`, `WeightPowerAttr`) | 헤비봄버, 히트스탬프, 안다리걸기, 풀묶기 | 없음 | 무게 데이터를 추가해서 계산 (`prompts/role-logic-redesign.md` 7절). 헤비메탈·라이트메탈·바디퍼지 반영 |
| 스피드 (`GyroBallPowerAttr`, `ElectroBallPowerAttr`) | 자이로볼(느릴수록), 일렉트릭볼(빠를수록) | 없음 | 종족값 스피드로 위력을 추정해 평가할 수 있음 |
| 상대 HP가 많을수록 강함 (`OpponentHighHpPowerAttr`) | 묵사발, 쥐어짜기, 하드프레스 | 없음 | 보스(HP가 많음) 상대로 강함. 최대 위력의 일부로 평가하거나 제외 |
| 기타 위력 없음 | 혼내기(상대 랭크업), 마지막수단(PP), 토해내기(비축) | 없음 | 제외 |
| 친밀도 (`FriendshipPowerAttr`) | 은혜갚기, 화풀이, 피카피카썬더, 브이브이브레이크 | 없음 | 제외 |
| 포켓로그 전용 | 다이맥스포 (상대가 웨이브 레벨 최대치를 넘으면 강해짐) | 기본 위력 | 기본 위력으로 평가 |
| 기타 | 물수리검(유대변화 개굴닌자), 테라버스트(테라스탈) | | `prompts/conditional-moves.md` 참고 |

**쓸 만한 경우 예시**
- 보스로라: 헤비봄버(레벨업, 자속), 히트스탬프(알기술). 무거워서 위력이 높게 나올 가능성이 크다.
- 쏘콘·강철톤·동탁군·자포코일: 자이로볼(레벨업, 자속). 느린 강철 타입이라 강하게 들어간다.
- 레지기가스: 묵사발(레벨업, 자속).
- 게을킹: 묵사발(알기술, 자속).

> **무게 데이터**: 서비스의 dex 데이터에는 지금 무게가 없다. 포켓로그 코드의 종·폼 데이터에는 무게가 있으므로, 추출 스크립트에 무게 필드를 추가해서 계산하기로 했다 (`prompts/role-logic-redesign.md` 7절).

## 5. 능력치와 무관한 고정 데미지 (14개)

공격·특공·방어·특방을 전혀 쓰지 않는다. 분류 판정과 화력 평가에서 **제외**한다. 지금도 위력 `-1`이라 자동으로 빠진다.

| 기술 | 데미지 (클래스) |
|---|---|
| 소닉붐, 용의분노 | 고정 수치 (`FixedDamageAttr`) |
| 지구던지기, 나이트헤드 | 사용자 레벨만큼 (`LevelDamageAttr`) |
| 사이코웨이브 | 레벨 기반 무작위 (`RandomLevelDamageAttr`) |
| 분노의앞니, 자연의분노, 카타스트로피 | 상대 남은 HP의 절반 (`TargetHalfHpDamageAttr`) |
| 카운터, 미러코트, 메탈버스트, 앙갚음 | 받은 데미지를 되돌림 (`CounterDamageAttr`) |
| 죽기살기 | 상대 HP를 내 HP에 맞춤 (`MatchHpAttr`) |
| 목숨걸기 | 내 HP만큼 주고 쓰러짐 (`UserHpDamageAttr`) |

## 7. 2턴에 걸쳐 공격하는 기술 (16개)

충전기 할인 규칙(`prompts/role-logic-redesign.md` 2절)의 대상이다. 첫 턴에 무엇을 하느냐에 따라 세 종류로 나뉜다.

| 종류 | 기술 | 판정 처리 |
|---|---|---|
| 충전만 함 | 칼바람, 불새, 프리즈볼트, 콜드플레어 | 충전기 할인 |
| 충전하면서 능력치가 오름 | 로켓박치기(방어 +1), 메테오빔(특공 +1), 일렉트로빔(특공 +1) | 충전기 할인을 덜 하고, 오르는 능력치는 랭크업으로 가산 |
| 첫 턴에 숨음 (공격을 피함) | 공중날기, 구멍파기, 다이빙, 뛰어오르기, 섀도다이브, 고스트다이브, 프리폴 | 충전기 할인. 숨는 턴에는 맞지 않는 장점이 있어 일반 충전기보다 덜 할인 |
| 날씨로 충전이 생략됨 | 솔라빔·솔라블레이드(쾌청), 일렉트로빔(비) | **본인 특성·패시브로 그 날씨를 만들면** 일반 기술과 똑같이, 또는 가산점까지 평가 |

- 쾌청을 만드는 특성: 가뭄, 끝의대지, 진홍빛고동
- 비를 만드는 특성: 잔비, 시작의바다

## 판정 로직에 반영할 요약

1. **포톤가이저**: 종족값 공격 > 특공이면 물리기로 바꿔서 평가한다.
2. **셸암즈**: 분류 증거로는 중립으로 두고, 주 분류 기준으로 평가한다.
3. **테라버스트·테라클러스터**: 테라스탈 조건부라 분류 판정에서 제외하거나 크게 할인한다.
4. **바디프레스**: 방어 능력치로 평가하고, 공격 분류 증거에서는 뺀다. 방어 특화 빌드의 공격 수단과 방어 랭크업 시너지로 쓴다.
5. **속임수**: 공격 분류 증거에서 뺀다. 막이·서포터의 공격 수단으로 쓴다.
6. **사이코쇼크·사이코브레이크·신비의칼**: 분류는 그대로 둔다. 특수막이를 뚫는 수단으로 기록만 한다.
7. **위력 변동 기술**: 4절 표의 묶음별 처리를 따른다.
   - 날씨·필드 조건은 본인 특성·패시브로 만들 때만 강화로 본다.
   - 상태이상 조건은 그 상태를 거는 기술이나 특성이 있을 때 가산한다.
8. **고정 데미지 기술**: 제외한다.
9. **무게 기술**: 무게 데이터로 위력을 추정한다. 헤비메탈·라이트메탈 배율을 반영하고, 바디퍼지와는 함께 추천하지 않는다.
10. **충전기**: 7절 종류별로 할인 정도를 다르게 하고, 본인 날씨로 충전이 생략되면 할인하지 않는다.
11. 이 목록은 `classic.json`에 기술 이름별 처리 방식으로 둔다.
    - 예: `variableCalcMoves: { "포톤가이저": "higherAttackStat", "바디프레스": "userDefense", ... }`
    - 게임 패치 후에는 리포트를 다시 뽑아서 새 기술이 생겼는지 확인한다.
