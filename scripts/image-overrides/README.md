# Image overrides

PNG files here replace the images copied from PokeRogue-Dex by `npm run build:dex`
(same layout as `public/images/`: `{img}.png`, `shiny/{img}_{tier}.png`).

| Image | Why | Source |
|---|---|---|
| `95.png`, `shiny/95_1..3.png` (Onix) | Dex image is missing the lower jaw | First frame (`0001.png`) of `pokerogue-assets` `images/pokemon/95` and `shiny/95`; tiers 2/3 recolored from the normal frame with `variant/95.json` |
