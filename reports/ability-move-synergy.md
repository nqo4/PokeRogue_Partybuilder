# 공격 기술을 강화하는 특성 전체 목록

> 자동 생성 파일 (`node scripts/report-move-lists.mjs`). 손으로 고치지 말고 스크립트를 다시 실행한다.
> 기준: 포켓로그 코드 `vendor/pokerogue` (1.12.2.8 915fae1) · 서비스 데이터 `public/data/dex.json`
> 배우는 포켓몬은 최종진화·메가 형태 기준, 레벨업(진화·기억버섯 포함)과 알기술만 표로 적고 기술머신은 수만 센다.


찾는 방법: `src/data/abilities/init-abilities.ts`에서 기술 위력·타입·자속·능력치(공격/특공)를 바꾸는 클래스(`MovePowerBoostAbAttr`, `MoveTypePowerBoostAbAttr`, `LowHpMoveTypePowerBoostAbAttr`, `VariableMovePowerBoostAbAttr`, `MoveTypeChangeAbAttr`, `StabBoostAbAttr`, `MoveDamageBoostAbAttr`, `MoveEffectChanceMultiplierAbAttr`, `FieldMoveTypePowerBoostAbAttr`, `UserFieldMoveTypePowerBoostAbAttr`, `AllyMoveCategoryPowerBoostAbAttr`, `StatMultiplierAbAttr`의 공격·특공)를 쓰는 특성.

"강화되는 기술"은 보유 포켓몬이 레벨업·알기술로 배우는 위력 있는 공격기 중 특성 조건에 맞는 기술이다 (위력 50 미만은 테크니션만 표시). 조건을 자동으로 읽지 못한 특성은 "수동 확인"으로 표시했다.

기술 표기: 기술명 + 위력, `(알)` 알기술, `*` 자속.
